🧑‍💻 Sobre mim

Tenho experiência prática no desenvolvimento de aplicações web completas, atuando tanto no front-end quanto no back-end.

Meu foco está em construir sistemas com arquitetura organizada, APIs bem estruturadas, persistência de dados, autenticação, testes, integrações e automações.

Também utilizo ferramentas modernas de AI-assisted development para acelerar pesquisa, prototipação, desenvolvimento, análise e documentação, mantendo o foco em compreender, revisar e validar o código produzido.

Tenho experiência explorando diferentes ferramentas e ecossistemas de IA, incluindo Claude Code, TRAE IDE, Ollama e modelos de IA via APIs, além de fluxos com agentes, skills e integrações personalizadas.
